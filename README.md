## 📖 О проекте

**FishTrack** — это система для автоматизации учета рыболовной фирмы.  
Позволяет вести учет катеров, команд и рейсов.

### 🎯 Назначение
- Управление парком катеров
- Ведение учета команд и капитанов
- Фиксация рейсов с датами отправления и возвращения

### 👥 Категории пользователей
| Роль | Возможности |
|------|-------------|
| **Администратор** | Полный CRUD доступ ко всем сущностям |
| **Менеджер** | Создание рейсов и просмотр статистики |
| **Капитан** | Просмотр своих рейсов (в будущем) |

---
## 🎬 Основные сценарии

### Сценарий 1: Добавление катера
1. Пользователь открывает `/web/boats`
2. Нажимает «+ Добавить катер»
3. Заполняет форму: название, рег. номер, вместимость
4. Система проверяет уникальность номера
5. Катер сохраняется в БД

### Сценарий 2: Создание команды
1. Пользователь открывает `/web/crews`
2. Нажимает «+ Добавить команду»
3. Заполняет: капитан, количество членов
4. Команда сохраняется

### Сценарий 3: Создание рейса
1. Пользователь открывает `/web/trips`
2. Нажимает «+ Добавить рейс»
3. Выбирает катер и команду из списков
4. Указывает даты отправления и возврата
5. Система проверяет: дата возврата ≥ даты отправления
6. Рейс сохраняется

## 📏 Обязательные правила работы

| Правило | Где применяется | Результат нарушения |
|---------|-----------------|---------------------|
| Уникальность `registration_number` | При создании катера | 409 Conflict |
| `capacity > 0` | Валидация схемы | 400 Bad Request |
| `members_count > 0` | Валидация схемы | 400 Bad Request |
| Существование `boat_id` | При создании рейса | 404 Not Found |
| Существование `crew_id` | При создании рейса | 404 Not Found |
| `return_date >= departure_date` | При создании рейса | 400 Bad Request |
