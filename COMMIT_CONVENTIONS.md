# 📝 Правила оформления коммитов

Мы используем **Conventional Commits** — стандарт для описания изменений в репозитории.  
Это делает историю проекта понятной, помогает автоматически генерировать changelog и упрощает работу в команде.

---

## 📋 Формат коммита

- **type** — тип изменения (обязательно)
- **scope** — область изменений (опционально, но желательно)
- **subject** — краткое описание (обязательно)

---

## 🏷 Типы коммитов (type)

| Тип | Описание | Пример |
|-----|----------|--------|
| **feat** | Новая функциональность | `feat(boats): Добавлен CRUD для катеров` |
| **fix** | Исправление ошибки | `fix(api): Исправлена валидация registration_number` |
| **docs** | Изменения в документации | `docs: Обновлен README.md` |
| **style** | Форматирование кода | `style: Применен black для форматирования` |
| **refactor** | Рефакторинг | `refactor(service): Оптимизирован запрос к БД` |
| **test** | Добавление/изменение тестов | `test(boats): Добавлены тесты для CRUD` |
| **chore** | Обслуживание (зависимости, настройки) | `chore: Обновлен requirements.txt` |
| **init** | Инициализация проекта | `init: Базовая инфраструктура` |

---

## 🎯 Scope (область изменений)

| Scope | Описание |
|-------|----------|
| `boats` | Катера |
| `crews` | Команды |
| `trips` | Рейсы |
| `api` | API в целом |
| `db` | База данных |
| `config` | Конфигурация |
| `docker` | Docker настройки |
| `docs` | Документация |
| `tests` | Тесты |

---

## ✅ Примеры правильных коммитов

```bash
# Новая функция
git commit -m "feat(boats): Добавлен CRUD для управления катерами"

# Исправление ошибки
git commit -m "fix(api): Исправлена ошибка при создании рейса с пустой командой"

# Документация
git commit -m "docs: Обновлена документация API"

# Тесты
git commit -m "test(boats): Добавлены тесты для проверки уникальности registration_number"

# Рефакторинг
git commit -m "refactor(service): Оптимизирован запрос для отчета по улову"

# Инициализация
git commit -m "init: Базовая инфраструктура проекта"

# Несколько изменений в одном коммите (с телом)
git commit -m "feat(api): Добавлен health-check эндпоинт

- Добавлен GET /health
- Проверка подключения к БД
- Добавлены тесты для health-check
"
