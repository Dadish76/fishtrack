# API Документация FishTrack

## Эндпоинты

### Катера (Boats)
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/boats` | Список катеров |
| GET | `/boats/{id}` | Получить катер |
| POST | `/boats` | Создать катер |
| PUT | `/boats/{id}` | Обновить катер |
| DELETE | `/boats/{id}` | Удалить катер |

### Команды (Crews)
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/crews` | Список команд |
| POST | `/crews` | Создать команду |
| GET | `/crews/{id}` | Получить команду |
| PUT | `/crews/{id}` | Обновить команду |
| DELETE | `/crews/{id}` | Удалить команду |

### Рейсы (Trips)

## Health Check

Пример ответа:
```json
{
  "status": "healthy",
  "service": "FishTrack"
}
```
## Ошибки
* 400 -  Некорректные данные
* 404 -  Сущность не найдена
* 400 -  Конфликт (нарушение бизнес-правил)
